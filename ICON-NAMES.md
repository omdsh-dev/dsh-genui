# Icon names — full catalogue

The `icon` node accepts any name below (`{"type":"icon","name":"…"}`).
Names are **case-sensitive** and taken verbatim from the OpenAI Apps SDK UI
icon set (MIT, pinned commit `0f00143c7a639906f1621fe58e1b6be7b5bea46d`).

## Why this file exists

The list is 753 names (~11 KB). Keeping it out of `SKILL.md` means the
skill does not pay that cost on every turn; read or grep this file only when
you actually need a glyph name that is not in the "inlined" list.

## Two tiers

| tier | count | behaviour |
| --- | --- | --- |
| inlined | 62 | ships in the client bundle, renders instantly |
| on demand | 692 | first use fetches `lib/assets/icons.js` (~900 KB) once per page |

A name outside this file renders a neutral dot — the block still renders, the
guard reports an unknown name, and nothing is downloaded.

## Find a name

```sh
grep -o 'Arrow[A-Za-z]*\|File[A-Za-z]*\|Voice[A-Za-z]*' ICON-NAMES.md | sort -u
```
